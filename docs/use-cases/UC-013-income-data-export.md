## 2. Summary

From the income dashboard (`UC-006`), the freelancer can download their income data for any selected month as a **CSV** or **PDF report**. The export applies the same filters currently active on the dashboard (month, source, category). The CSV contains raw rows for use in Excel or accounting tools. The PDF is a formatted monthly income summary — totals, per-source and per-category breakdown, and individual entry rows — suitable for record-keeping or sharing with an accountant.

---

## 3. Actors and context

### Primary actor

Authenticated freelancer or small business owner.

### Secondary actors

- **System:** Laravel MVC; DomPDF (PDF); PHP native CSV stream

### Preconditions

- [ ] User is authenticated
- [ ] At least one `income_entries` row exists for the selected period

### Postconditions (success)

- [ ] A CSV or PDF file is streamed as a download — no file stored on disk

### Postconditions (failure — if applicable)

- [ ] If no income entries exist for the selected filter, a flash message is shown: *"No income data found for the selected period."* — no file download

## 5. User journey (happy path)

### 5.1 Export trigger

1. On the income dashboard (`GET /income`), an **"Export"** button sits in the top-right of the income list section.
2. Clicking it opens a small **dropdown** with two options:
   - **"Download CSV"**
   - **"Download PDF report"**
3. Selection navigates to:
   - `GET /income/export/csv?month=2026-04&source=all&category=all`
   - `GET /income/export/pdf?month=2026-04&source=all&category=all`
4. The query parameters mirror the active dashboard filters at the time of export.

### 5.2 CSV export

Controller queries `income_entries` with applied filters, then streams a CSV response:

**CSV columns:**
```
Date, Amount, Currency, Source, Client, Category, Description
```

**Example row:**
```
2026-04-20, 2850.00, EGP, Payment Link, Ahmed Hassan, Freelance, "Logo design project"
```

Response headers:
```
Content-Type: text/csv
Content-Disposition: attachment; filename="income-April-2026.csv"
```

### 5.3 PDF report

Controller renders a **Blade → DomPDF** view with:

1. **Header:** "Income Report — [Month Year]" · Freelancer display name
2. **Summary section:**
   - Total income (period)
   - Breakdown by source (table: Source · Count · Total)
   - Breakdown by category (table: Category · Total)
3. **Income entries table:** Date · Client · Category · Source · Amount
4. **Footer:** *"Generated by Financial OS · [timestamp]"*

Streamed as a download:
```
Content-Disposition: attachment; filename="income-report-April-2026.pdf"
```

- **Stream-only:** No disk write or S3 for either format.

- **Demo:** Use seeded data with 6–8 income entries across two sources so the PDF breakdown section is non-trivial.

## 9. Acceptance criteria (testable)

- [ ] Given the income dashboard with a selected month, when the user clicks "Download CSV", then a `.csv` file downloads with one row per income entry in that month
- [ ] Given the income dashboard, when the user clicks "Download PDF report", then a `.pdf` downloads with a summary section and entries table
- [ ] Given active filters (e.g. source = Manual), when the user exports, then only matching entries appear in the file
- [ ] Given no entries for the selected period, when export is attempted, then a flash message is shown and no file downloads
- [ ] Given an unauthenticated request to the export endpoint, then `401` is returned

---

## 10. Scope boundaries

### In scope

- CSV and PDF export of income entries for a selected month with active filters
- Summary section in PDF (total, by source, by category)

### Out of scope

- Multi-month or full-year export (post-MVP)
- Expense export (post-MVP)
- Storing exported files (stream-only)

## 11. Demo script snippet

1. Open the income dashboard with April 2026 selected and seeded data visible.
2. Click **"Export"** → **"Download CSV"** — show the downloaded file in Excel with all columns.
3. Click **"Export"** → **"Download PDF report"** — open the PDF, show the summary section and entries table.

## 12. Decisions (resolved)

| Topic | Decision |
|-------|----------|
| Export formats | CSV (raw data for tools) + PDF (formatted report for accountants/records) — both serve different user needs |
| Filter carry-over | Export uses the same filters active on the dashboard at the time of click — no separate filter UI on the export |
| Storage | Stream-only — no S3 or disk writes |
